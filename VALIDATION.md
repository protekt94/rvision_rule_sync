## Исключение тестов и разметка критичных изменений

Проверены добавление/изменение/удаление test и tests: они не влияют на статусы,
структурные diff и хеши блоков обоих режимов. При AUTO_MERGE их содержимое
сохраняется из custom, включая отсутствие блока. Полный хеш целостности BASE
не изменён, чтобы поддерживать ранее созданные рабочие папки.

Проверены несколько отмеченных областей, вложенные пути aliases и списки,
CRLF и сериализация, непарные/вложенные маркеры, обязательный review,
сохранение критичного кода при независимом merge и конфликт при изменении
одного VRL-блока обеими сторонами. Markdown показывает отдельные фрагменты
и защищает границы code fence; tests не попадают в diff или разметку.
Интеграционный тест analyze проверяет сохранение tests и маркеров в кандидате.

Примеры отчётов пересчитаны на сохранённых реальных снимках. Оригиналы fixture
не менялись. Пример examples/marked-custom/VI-D-971.ro — копия исходного VI
с добавленными комментариями вокруг groupedBy; пример не подменяет оригинал.
